- Unicode Standard **17.0.0**, [§3.12 Conjoining Jamo Behavior](https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-3/):
  arithmetic syllable composition/decomposition and L/V/T ordering.
- Unicode Standard **17.0.0**, [§18.6 Hangul](https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-18/):
  modern syllable and jamo ranges.
- Microsoft's [Korean IME documentation](https://learn.microsoft.com/en-us/globalization/input/korean-ime)

These are references for character ordering and keyboard behavior, not imported
build inputs. Unicode and Microsoft retain the rights to their own documents;
the project's MIT license does not relicense those documents.

## Generation / 生成规则

The generator declares modern Dubeolsik strokes for 19 initials, 21 vowels and
27 finals in Unicode order. It enumerates 19 × 21 × 28 = 11,172 syllables,
stores both precomposed and fully decomposed forms, adds 67 modern conjoining
jamo and 51 compatibility jamo, then sorts by UTF-8 text bytes and writes one
text/code pair per TSV row. Complex vowels and final clusters concatenate their
component key strokes. No weights, translations, word list or romanization is used.

维护脚本按 Unicode 顺序声明键位，生成预组合与规范分解音节，补现代组字字母和兼容字母，
按 UTF-8 字节排序写 TSV。共 22,462 行，不含词频、翻译、词库或罗马音。

There are **no external input files**, so there is no external-input hash to report.
[data.json](data.json) records the generator SHA-256, output SHA-256, specification
version and counts. Regeneration requires only Neovim, without network access.
没有外部输入文件；data.json 记录生成脚本和产物的 SHA-256、规范版本和条目数，生成无需联网。
